# Multimetrix - Usługi Budowlane 🏗️

Projekt strony internetowej zrealizowany w ramach przedmiotu **Techniki Internetowe**.

Celem projektu było stworzenie profesjonalnej wizytówki dla firmy budowlanej, zawierającej galerię realizacji, sekcję opinii oraz dane kontaktowe. Projekt został jednak rozszerzony o niestandardową funkcjonalność JavaScript (mini CTF), która zmienia charakter strony na satyryczny z motywem bajki "Sąsiedzi".

## 🚀 Funkcjonalności
* **Strona Wizytówka:** Responsywny Landing Page dla firmy budowlanej.
* **Dynamiczna Galeria:** Slider zdjęć napisany w czystym JavaScript (bez zewnętrznych bibliotek) z funkcją automatycznego przewijania i obsługą interakcji użytkownika.
* **Ukryty Tryb "Sąsiedzi" (Easter Egg):** Zaimplementowany panel logowania, który po podaniu odpowiednich danych logowania dynamicznie podmienia zawartość strony (teksty i zdjęcia). W tej wersji "właścicielami" firmy stają się bracia Pat i Mat.

## 🛠️ Technologie
* HTML5
* CSS3
* JavaScript 

## 🕵️‍♂️ Jak uruchomić Easter Egga?
W prawym górnym rogu strony znajduje się panel logowania.
Dane potrzebne do logowania zostały ukryte gdzieś w kodzie strony, a twoim zadaniem jest je odnaleźć i odszyforwać.

Po zalogowaniu skrypt JS podmienia ścieżki do zdjęć oraz treści na stronie, demonstrując mechanizm manipulacji atrybutami.
